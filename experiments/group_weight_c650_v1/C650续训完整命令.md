# C650续训完整命令

2026-11-24。用户指定在C500独立Dev25/50、Final138/200之后继续至650。原C500阴性/混合结果保持，不据此声称方法有效。本入口只训练，不自动独立评测或继续800。

## 1. 无卡拉取、CPU验收和准备

从c500_active_run.txt定位原C500，绑定刚评测过的完整500 Actor SHA，不使用合并权重作RL恢复。校验模型/优化器/extra/data恢复文件、CRC、原环境/SFT/数据身份；需要读取约10GiB文件并计算哈希，请等待。保存收据原件及测试日志。新目录至少需3份恢复点瞬时空间＋4GiB日志余量（以实物大小计算，约35GiB）。

```bash
cd /root/autodl-tmp/work/my_shopping_agent
bash <<'BASH'
set -euo pipefail
ROOT=/root/autodl-tmp/work/my_shopping_agent
cd "$ROOT"
mkdir -p "$ROOT/outputs"
LOG="$ROOT/outputs/c650_prepare_$(date -u +%Y%m%dT%H%M%SZ)_$RANDOM.log"
exec > >(tee -a "$LOG") 2>&1
trap 'rc=$?; printf "PREPARE_EXIT_CODE=%s\nLOG=%s\n" "$rc" "$LOG"; if [[ "$rc" != 0 ]]; then echo "准备失败，保留日志，不要启动有卡run。"; fi' EXIT
[[ ! -e "$ROOT/outputs/c650_active.txt" ]] || { echo 'C650已准备，请使用status/return。'; exit 1; }
CODE=$(mktemp -d "$ROOT/outputs/c650-code-XXXXXX")
printf 'CODE=%s\n' "$CODE"
git -c http.version=HTTP/1.1 clone --depth 1 --single-branch --filter=blob:none --sparse --branch codex/c650-training "$(git remote get-url origin)" "$CODE"
git -C "$CODE" sparse-checkout set tools experiments/group_weight_c500_v1 experiments/group_weight_c650_v1 experiments/group_weight_b500_v1 analysis/grpo_mechanism_audit_20261116/package_reference analysis/online_training_window_return_20261116
export OMP_NUM_THREADS=1
bash "$CODE/tools/c650_commands.sh" prepare
BASH
```

必须看到C650_PREPARED=true、NATIVE_CPU_PASSED=true及PREPARE_EXIT_CODE=0再继续。严格模式只在子bash生效，失败不关闭交互终端。已有目录/指针不覆盖，准备失败保留LOG发回，不重复启动训练。

后台运行，不要重复run；无600预设重启，不重新warmup。恢复开始的进度条通常从500/650附近显示，终点650。首个新更新501及最终650将写验收收据。PID不等于恢复成功，需查第4段。
