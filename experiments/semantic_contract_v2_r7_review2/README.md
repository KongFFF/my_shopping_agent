# r7-review2：验收14题修订用校验器

继承冻结r7-review的字段和政策，不自动升级LLM提取profile，不接入训练或奖励。新增两个来源受限的修复：

- “且／并且价格”等明确货币分句不借用前面的附件/购买数量；不会删掉每瓶等单价分母。
- “要两个筒的设计”等已完整保留的内部结构计数不强制当订单数量；明确“买两个”和遗漏结构数量仍阻断。

来源实现为 `tools/semantic_acceptance_fixes.py`，没有按task_id绕过验证的分支。旧r7、r7-review及其验收样本保持不变。
