磁盘需至少3份完整恢复点＋4GiB日志余量（按实物计算，约35GiB空闲）。使用新代码目录、浅克隆和稀疏检出，避免拉取全部历史结果。失败保留日志，不覆盖已有目录或启动GPU。

```bash
cd /root/autodl-tmp/work/my_shopping_agent
bash <<'BASH'
set -euo pipefail
```
