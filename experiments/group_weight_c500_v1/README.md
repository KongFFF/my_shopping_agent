## 比较命题

γ定义为含成功组S原始权重除以全失败组F原始权重，固定S＝1、F＝1/γ。A原GRPO等价γ＝1，既有B为γ＝2，新C为γ＝4。C只检验加大该权重强度是否改变结果，是同一方法的强度消融，不宣称新算法，也不预设加大权重一定有利。

在B的全局Actor有效token归一化下，F/S实际系数分别为(N_F+N_S)/(N_F+γN_S)和γ(N_F+N_S)/(N_F+γN_S)。混合批次两侧token数相等时，C系数为0.4/1.6，B为2/3与4/3；FF或SS批次均回到系数1。因此不是所有F轨迹都只学原来的25%。正/负优势同乘该系数，原PPO裁剪、mask、优势中心化及UID关联保留。
