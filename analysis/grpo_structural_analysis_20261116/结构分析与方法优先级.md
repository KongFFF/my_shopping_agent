# 原GRPO结构分析与方法优先级

2026-11-16。本轮只使用已有结果和CPU统计，没有新增模型采样、训练或Final评测。

## 结论与边界

**当前最值得进一步验证的关键假设是：整条轨迹共用一个优势值，对多阶段购物决策提供的信用分配过粗；但在每题仅4条轨迹的条件下，直接构造局部优势又容易受后续行为和小样本影响。优先研究“有证据约束的局部信用分配”，保留整局GRPO作为基础。**

这是方法候选的优先级判断，尚不是“已查明导致GRPO提升有限的首要原因”。本轮没有估计真实策略梯度、梯度方差或训练后的成功率，不能承诺涨幅。原GRPO已经比SFT高4.5个百分点，也没有被证明收敛；本报告研究的是进一步提升的可能机制。

原方法的数学实现没有因此被判为错误。终局回报的策略梯度可以学习多步行为；同一动作在失败轨迹中获得负优势，也不自动等于错误梯度。我们要验证的是局部信号能否降低无关后续结果的干扰、提高学习稳定性，而不是给原实现贴“算法失效”的标签。

失败轨迹的搜索量更高，但不能因此统一惩罚搜索：均匀层成功轨迹84条共92次搜索、8次返回搜索；失败44条共94次搜索、51次返回搜索。成功轨迹仍可能需要探索，例如3727有6步和14步两条成功路径。搜索多可能是困难程度的结果，不能从相关性得出“少搜索即可提高成功率”。

### 公开信息复核及反例

可检查的页面和人工判断分别保存在[public_case_review.json](public_case_review.json)，未把人工判断混入原生成功统计。

- **候选/组合选择：** 3727需求为约20ml、约30杯、一盒；失败买15ml×两盒，同批成功买18ml×32杯×一盒。18330需求包含120W泵、定时插座和50米管、1350元内；失败所开商品最低1700元，仍购买。这不是缺乏终局负反馈，而是还没有稳定学会利用候选和反馈。
- **落实与提交：** 20628选完套餐后二次显示125元，公开上限120元，仍买；同题有套餐一成功。5535直接空规格购买，没有落实公开的数量与赠剂，菜单中存在相应组合。
- **恢复/终止：** 2013失败路径曾到同题成功商品并选到69元碳化色，随后改104元大号、离开，最终35步耗尽。颜色映射存在语义近似，不能把同题Gold当作唯一语义答案，但该轨迹确实没有保留已经获得的候选成果。
- **反例：** 22462的红杆105元失败购买与公开“红色笔杆、110元左右”相符；不能因为另一型号是Gold就认定它选错。19827已经选8成新Z20、700元，少点单值“官方标配”，主要反映环境完成惯例。4060颜色不限不意味着只能选“随机颜色”，但粉色20元确实不满足严格低于20元。

因此，不把29条失败全部算成可以靠新算法修好的能力错误，也不把本次11道零成功题全部叫作难题。后者包含规格/价格无法确认、公开语义与标签关系不清及上下文错误；这些不构成本轮主要方法的收益预估。

## 3. 原训练信号：整局比较持续存在，成功参照却并非每组都有

沿用已完成的源码及日志核验：实际配方`norm_adv_by_std=false`，标量优势为

`A_episode(i) = R(i) - mean(R(同题四条轨迹))`

原训练把该优势广播到该轨迹生成的assistant token，工具回复不参与Actor损失。两窗共300次更新的优势极值与此重构一致；这不是对历史每个token张量的独立重放。实际配置无额外KL或熵奖励，Actor损失为token-mean。源码核验出处为[原机制审计](../grpo_mechanism_audit_20261116/)，本轮没有修改配方。

|---|---:|---:|
| 总组数 | 300 | 300 |
| 组内0条成功 | 100 | 85 |
| 组内1条成功 | 61 | 51 |
| 组内2条成功 | 57 | 57 |

| 失败但标量优势为正的轨迹 | 231 | 185 |

后段185条正优势失败中，168条部分匹配购买、14条循环结束、3条步数耗尽。**这是组内相对评价的正常结果，不是“失败被错误奖励”的实现bug。**较好失败可以提供进步方向，但本批没有成功例子时，该更新无法直接比较“部分匹配购买”和完整成功路径。

已有历史中，后段85个零成功更新组有22组的任务此前出现过原生成功；另外119个因恒定奖励丢弃的零成功生成组中，有17组此前出现过成功。历史只含351—500和当前组之前的651—800日志，未使用未来结果，缺0—350/501—650。它支持“有些题曾做对但当前仍不稳”，**不足以证明遗忘、估计历史成功概率或断言回放一定改善**。

这些信号共同指向两个待检验机制：局部决策比较可能不够有效；少数困难组缺少当下成功参照。前者是当前优先项，后者暂作方法层备选。

## 4. 自然局部比较是否真实存在

不额外采样，只在同一题、同一个四轨迹组中寻找已有的**动作之前**公开页面。排除初始搜索主页，避免把原整局分组算作新信息；每条轨迹同一状态仅保留首次访问，循环访问不增加独立证据量。每组四条都有效，原训练还要求四条恢复均获认证。

同时比较三种匹配键：当前投影文本；投影文本+剩余步数；投影文本+完整已执行工具/公开观察历史。最后一种仍没有assistant思考文本，不等于完整Actor上下文。绝不使用隐藏goal、购买结果或终局奖励决定“状态相同”。

“新增局部比较”保守定义为：至少两条不同轨迹到达、动作不同、最终奖励不同，且在γ=1时其局部组均值区别于原四轨迹均值。这衡量信号会不会区别于原GRPO，**不等于判定该信号正确**，也不是完整复现GiGPO。

后段带工具历史的56/195组表明：局部比较在真实训练中并非偶发现象，不必靠新增状态续采才能获得。但它仅覆盖165/6941个决策位置；未认证105组以及无证据位置均不能外推。决策位置少也不自动意味着性能影响小，瓶颈动作可能集中；反过来，覆盖56组不表示56组都会受益。

### 真正的制约是证据可靠性

后段仅页面匹配的245个动作/奖励变化键中，61个包含“同一动作、不同终局回报”，只有23个键的每种动作都有至少两条轨迹支持。带工具历史后：88个变化键中20个仍有同动作不同回报，每种动作至少两次的只有4个。

同一动作可能因后面不同的选择、搜索或错误而得到不同回报。例如固定800的22462在相同工具历史后，两条都`back_to_search`，最终却分别为1和0.04375；不能将一次最终成功全部归因于这次返回动作。该题还有语义偏好不确定性，更不能拿它作正面训练标签。

因此，直接把终局分差当作局部动作质量、把不同历史下相同页面无条件合并，风险都高。采用严格“每动作≥2”硬门槛又可能几乎没有增量覆盖。**本轮没有在看到这些结果后宣布一个自设门槛已通过；如何在可靠性和覆盖之间取舍，正是下一阶段要回答的问题。**

详细分母与状态键见[online_anchor_summary.json](online_anchor_summary.json)、[summary.json](summary.json)；原组UID、局部动作及回报见[online_anchor_examples.json](online_anchor_examples.json)。这些观测对比不构成局部动作的因果实验。

## 5. 方法优先级与否定条件

### 优先：有证据约束的局部信用分配

方法范围是：保留原整局GRPO；在本次在线rollout中识别可比较的公开决策状态，构造局部动作信号；根据不同动作的支持量、同动作回报差异和历史可比性控制其权重；证据不足回退到原整局学习。训练时仍使用每个动作原来的Actor历史，不把上下文拼成虚构轨迹。

示意形式为`A(i,t) = A_episode(i) + λ × w(context) × A_local(i,t)`，其中`w`如何计算、`A_local`用动作平均还是其他估计都**尚未确定**。示意式不是已验收算法，不能直接照式上800步。

它改变的是Actor学习信号的构造，而不仅是多保留几组数据或修改推理prompt。它也不新增奖励模型、critic或默认增加生成次数，适合当前成本约束。实际接入仍需准确记录动作与生成token的对应关系；本轮未开发训练实现。

相关原始研究：GiGPO从已有整局轨迹的重复状态构造层次优势；ECPO进一步按动作证据量收缩、抑制状态内噪声；MCGPO讨论上下文匹配、独立证据与局部偏好目标。这些论文支持该问题值得研究，不能把其WebShop涨幅当作本项目预期收益，也不能把迁移已有方法称为自行发明算法。[GiGPO](https://arxiv.org/abs/2505.10978)、[ECPO](https://arxiv.org/abs/2606.05885)、[MCGPO](https://arxiv.org/abs/2610.13755)。

**会否定或降级该方向的结果：** 加入必要历史条件后覆盖接近零；局部动作排序随证据划分频繁反转；有效信号主要来自评分歧义；局部信号与原整局信号实质重复；短训练只提高代理奖励而不改善训练Dev单次成功，或破坏原本的成功行为。出现这些结果应停止，而不是不断放宽状态匹配或追加采样追正结果。

### 备选：历史成功的选择性自模仿

已有成功路径可以通过独立监督辅助目标保留，尝试补充当下零成功组缺少的成功参照；历史轨迹不能伪装成当前on-policy样本参与PPO比率计算。其思想有既有Self-Imitation Learning先例，原论文是带价值模型的off-policy actor-critic，本项目若用监督辅助项只是借鉴，不能称直接复现。[SIL](https://proceedings.mlr.press/v80/oh18b.html)。

当前证据覆盖有限，也没证明遗忘；可能只是维持SFT已有行为、引入额外教师强制成本或过拟合旧成功。暂列第二，不与局部信用分配同时加入，避免两轮预算无法拆分贡献。

单纯增加组大小、给所有长轨迹加惩罚、按公开约束逐题打补丁均缺少本轮证据支持成为当前主方法。其他小问题仅登记到备选修复文档。

## 6. 下一步唯一优先动作

**设计并冻结局部学习信号的CPU资格核查，再决定是否实现和短训。** 本轮第一步首轮结构分析完成；第二步没有开始。

资格核查应比较整局GRPO、朴素页面局部信号、带历史及证据约束的局部信号：排除初始状态和标签不明案例，统计真正新增覆盖、动作支持量、同动作回报噪声、可分割证据上的排序稳定性，以及信号是否仅放大原优势。每题4条时无法构造独立验证的情形必须记为证据不足，不能用同一结果同时构造偏好并证明偏好正确。

CPU结果只能确定“信号是否有资格进入训练”，不能证明性能提升。如覆盖和可靠性无法同时成立，就降低该方向优先级。需要新采样或短训练时另行给出具体可审查的成本协议，不自动消耗完整训练预算。

800仍为当前失败结构的主要诊断模型；正式对照起点未冻结。若从SFT开始，要匹配普通GRPO和方法组；若从800续训，也要有同起点同预算的普通续训对照。改进模型多训练后仅超过旧800，不能分离方法和额外更新的贡献。500步阶段检查可以预设，但不能拿改进500与原800混作同计算对照。

本轮没有足够证据给出“预计提升X个百分点”，也没有可以直接推荐消耗800步预算的已验证方法。
