# F/S组重加权：统一轨迹分析与机制解释

2026-11-22。分析已完成。范围为1350条原协议评测轨迹、B完整800次有效更新的6400条训练轨迹及A两个历史更新窗口。材料、重建规则和限制见[分析口径](分析口径.md)、[来源清单](source_manifest.json)。没有新增模型推理或训练，没有使用旧4192条复评轨迹。

## 结论先行

**本配置有少量可见需求匹配的稳定改善，但未把它扩展为稳定净收益。早期领先被原方法追平，部分既有成功路径未保持，大多数持续失败没有解决。** 这比“方法完全没作用”或“只是还没训够”都更符合现有轨迹。

训练机制上，F/S标签主要决定已有信号的强弱，不能区分同一个F组里有益的相对比较与可能误导的鼓励。它同时压低F组的正、负优势，并提高混合批次S组的正、负优势。这个实际变化可精确核查；具体哪部分参数更新导致某道题退步，当前历史单链不能因果定位。

同训练步数的原协议严格成功数如下。A是原GRPO，B是F0.5/S1；两个集合分开报告。

| 固定端点 | Dev A → B | Final A → B |
|---|---:|---:|
| 500 | 27 → 28 /50 | 137 → 141 /200 |
| 650 | 26 → 25 /50 | 141 → 143 /200 |
| 800 | 29 → 28 /50 | 143 → 142 /200 |

B800相对A800的Dev新增2/退步3、Final新增6/退步7。此前固定800配对分析的95%bootstrap差值区间为Dev约[−10,+6]个百分点、Final约[−4,+3]个百分点；不能由各少1题推断方法显著有害，也未证明稳定优于原GRPO。SFT历史为24/50、134/200，B与原A都较其提高；这不能替代B优于A的证明。Final已多次观察，不能重新称作未见测试。

## 一、收益与退步集中在少量题，且有反复

| B链500/650/800的严格成功状态 | Dev50 | Final200 |
|---|---:|---:|
| 三个端点始终成功 | 23 | 136 |
| 三个端点始终失败 | 20 | 51 |
| 至少发生一次成功/失败切换 | 7 | 13 |

同端点A/B的成功状态在三个位置都相同的题有Dev40/50、Final182/200。这不代表这些题的动作完全相同；例如A800/B800完整工具调用序列完全相同的为Dev32/50、Final132/200。

从B500到B800，Dev新增8666、10077，丢失13399、14141，净0；Final新增6219、7670、9688、14797，丢失12353、12997、13431，净+1。中途还存在11282、9378、12128、4413等只在B650成功的题。最终分数变化小，并不意味着每道题都没有变化，而是改善与退步互相抵消。

数据见[逐题矩阵](task_matrix.json)、[所有配对变化](changes.json)。A500 Final没有原动作材料，只用原成功ID确认500的分差，不编造其具体失误。

## 二、确实存在跨端点保持的需求匹配改善

| 任务 | 三个B端点均成功、同端点A均失败时的主要可见变化 |
|---|---|
| Dev3485 外套 | 用户要标准款；同页的米白色/米白色常规可区分，B持续选常规 |
| Dev4128 500g商品 | A在20/10瓶178/91元后循环；B最终恢复500g-1瓶9元，数量与约十元更匹配 |
| Final7424 音箱 | B检查79元候选后继续找到59元、明确1800毫安文字转语音SKU；B800用了17步 |
| Final11000 镜子 | A800带灯240元超预算后改成不带灯152元；B换候选买带灯150元，同时落实两项要求 |
| Final18125 衣服 | 同商品同价格，A650/A800选M驼色裤子，B持续选M酒红上衣 |

这5道是本链中稳定的原指标优势，其中公开文本也支持规格、数量、颜色、功能或价格匹配的改善。不是把任意gold切换都算语义进步；A500 Final只能核对状态，表内Final的A动作解释主要依据650/800原轨迹。这些也不是独立seed复现或实物功能认证。

另一些B500领先没有扩大，因为A继续训练后追上：Final15576、9819在A650/A800也成功；Dev13399在A650已成功，14141在A800成功。因此，B500的早期分差不能直接当终点优势。

## 三、退步包含候选利用、需求核验和结束决策三个环节

### 1. 已经找到有公开支持的候选，却未完成

**Dev13399硬盘底座**：B500/B650和A800均16步成功。B800第16步已打开同一麦沃候选，公开key_attributes明确扩存80TB，第17步选迷你标准版-脱机克隆+联机读写，699元；看完信息后第22步离开，反复搜80TB，最后35步max_steps。这道不是没有召回，也不是多给搜索机会就必然改善；已有完成路径没有保持。

**Dev14141洁牙设备**：B500成功，B650/B800循环。B800第1个结果页已显示阿里健康大药房、357元、可视化/超声波/家用候选，后续同查询也反复显示，却一直未打开；转而检查多种其他候选直至24步循环。这里有明确的可见候选利用问题，不对医疗性能作判断，也不将单链回退直接命名为灾难性遗忘。

### 2. 尚未有效找到候选，查询没有抓住关键用途

**Final3589金字塔模具**：A800翻页后找到23元白色食品模具；B800反复围绕金属定型/金属压花查询，打开钢丝、月饼模具，未见该候选便循环。这里与13399不同，需要改善检索表达及恢复；不能把所有循环都解释成该买时不买。

### 3. 存在真实规格—预算冲突，不宜简单催促购买

**Final13431烤盘**：B500/B650已成功，B800第10步也打开同一康佳商品，第11步选大号259元，第12步改可拆大号379元后离开，25步循环。用户明确要可拆且260以内；页面标题泛称可拆，SKU却区分大号/可拆大号。可以确认最终没有完成，但不能只靠A的gold标注断言259元款一定可拆。把这种核验困难简单改成少搜索、早点买，会引入另一类错购。

相反，Final7424的额外搜索确实找到了更合适的59元配置；Final4413在B650用34步找到2—6岁河马枕1299元，B800只用14步便买了缺该年龄/图案支持的普通枕。**统一罚长、统一鼓励更多搜索，都没有得到这批轨迹的充分支持。** 关键在新增动作是否解决了需求不确定，而不只在步数长短。

## 四、错误购买少4题，不等于多解决4题

A800到B800的Final错误购买从10变6，循环从9变13，实际转移为：

| 原A800 → B800 | 题数/任务 |
|---|---|
| 错误购买 → 循环 | 3：2717、13914、1848 |
| 错误购买 → 成功 | 1：7424 |
| 错误购买 → partial | 1：7506 |
| 成功 → 错误购买 | 1：9378 |
| 成功 → 循环 | 2：3589、13431 |
| partial → 循环 | 1：999 |
| 循环 → 成功 | 2：18495、22757 |

三道wrong→loop仍是两种失败之间的转换。7506从3680元超出2500上限，变成2480元，有公开预算遵守改善，但还没有严格成功。15991从35步max_steps变17步partial，却买了200元商品，仍不在query要求的350—450区间。仅看错购数、完成数或平均reward，都会遗漏这些区别。

## 五、部分原指标切换不能直接当语义能力变化

所有原分数保留，不重新判分或把模糊失败加回成功：

- **2898**：同鞋同价同41码，差异为100074689/100074690，实际观察没有深蓝代码映射。
- **5293**：犬肠道2kg、267元的主配置相同；A500额外选单值0lb才gold，不能当真实重量能力差异。
- **8666**：B500到B650从1个改为买10送1有实质数量改善；B650到B800的新增gold主要是补单值颜色轴规格。
- **11282**：779粉红色与jj99-29粉色切换，鞋码、内长和69元相同；query没有型号，缺外观映射，不能直接算识别粉色的能力反复丧失。
- **12353**：SC-607E与SC-537E切换；query未指定型号或具体容量，实际Features空，不能由gold差异断言前者才满足容量大。
- **9378**：单层20cm吧唧架19元与另一ins单层款17元之间切换；前者部分公开条件也匹配。wrong_purchase标签本身不能证明全部真实需求都错。

12128、12997则属于购买核验依据变弱：全套四层货架缺组件映射；另一阀门未看到赠送生料带/卡箍的说明。缺少证据不能直接反推实物一定没有。A800相对B800的Final7个严格退步，可以分为2个执行失败、2个验证依据变弱、3个语义/标注不确定，不能全写成7个已确认的模型认知错误。

完整45题的助手审阅见[case_reviews.json](case_reviews.json)，逐步公开摘录与观察哈希见[review_evidence.json](review_evidence.json)。其中31题覆盖全部成功状态变化，10题覆盖A800/B800双方失败但终止类型改变，4题补充持续失败Dev。它们不构成全250题的独立语义错误率。

## 六、从真实训练信号看，组级降权做了什么

已接通B规范1—800权重日志，含回滚前正确前缀及后续新链，共1600组、6400条Actor更新轨迹。实际优势均与同组终局utility减均值一致，误差在3e-6内；6400条日志的正/负token数也支持每条轨迹的优势基本为常数。这里没有构造新的局部学习信息。

800次更新为SS372、FF79、FS349。**只有349/800=43.6%的混合FS批次改变相对学习强度**；纯FF/SS归一化后系数回到1。0.5是原始相对权重，不是所有F轨迹一律少学50%。在两组token量相同的FS批次，实际系数为F的2/3、S的4/3。

定义当次可核查代理量：每条轨迹的有效token数×绝对原始优势÷全更新有效token数，再跨800次更新求和；乘日志中的系数得到修改后值。**这只是相同已采集B批次上的优势暴露量，不是实际梯度、PPO裁剪损失或从SFT重训A的反事实。**

| 优势方向 | 原系数1 | 实际重加权 | 变化 |
|---|---:|---:|---:|
| F组正优势 | 22.864 | 17.936 | −21.6% |
| F组负优势 | 30.117 | 23.912 | −20.6% |
| S组正优势 | 135.671 | 150.234 | +10.7% |
| S组负优势 | 149.766 | 165.198 | +10.3% |

F组原本占31.7%的更新组，但上述暴露代理份额约15.7%，重加权后约11.7%。F正优势1053条，其中940条partial、100条循环、13条max_steps；F负优势973条，其中337条循环、337条错误购买、287条partial、12条max_steps。**原方案不能只消除可能不好的正向鼓励：它也同时减弱了对这些失败结果的负反馈。** partial的相对比较有多少真正有用，现有只有动作/奖励摘要的训练日志不能逐条裁定，不能预设940条都是错误学习。

具体例子：第78步F组有循环utility−0.65和三条错购−0.85，循环优势为+0.15，错购为−0.05；同一个0.676系数同时缩小它们。第2步F组则是三条partial相对优于循环，压低同一组会同时压低相对进展和循环负反馈。相对优势反映奖励里的次序，正优势不自动等于整局正确，F标签也不自动等于信号错误。

**一个需要排除的简单归因：** 虽然F循环负优势代理减小，S的对应负优势被放大；F+S合计的循环负优势代理实际增加约2.7%，错误购买负优势代理增加约2.2%。因此不能写成循环多是因为总体少惩罚循环，也不能从上述代理量直接断言增强了哪些参数方向。

F/S还不是固定题目难度分类：212道题进入过F组，396道进入过S组，78道两类都出现过。S组1093个中仅5个没有gold，因此本轮也不支持把主要原因归到S标签大量混入非gold；这不是值得优先投入的新小修补。

## 七、为什么这类重分配难以解决剩余主体

规范路径实际生成覆盖1000道训练题，共7086组；1600组进入Actor，覆盖530道题。未进入Actor的470道应拆开看：

| 未更新题的已有观测 | 题数 |
|---|---:|
| 所有观测组均全native成功 | 356 |
| 所有观测均没有native成功 | 77 |
| 看过有效有差异组，但未进入更新 | 29 |
| 不同组间成功/失败混合 | 8 |

不能把470全当未利用的困难题，多数已经观测全成功；也不能由77题未见成功推断永远不可解。F/S权重只作用于进Actor的组，不改变这些题的探索或筛选，不能凭已有数据声称回收组、加采样就会显著提高Final。训练生成题ID与Dev/Final无交集。

评测中，20道Dev、51道Final在B三个端点均失败；其中11道Dev、21道Final的完整工具调用序列也完全相同。持续失败仍包含明确公开约束未落实：12066在276元状态购买却要求250以内；16252空规格下单，未落实分体/容量/自动/质保；20134买金玉满堂而要事事如意；23126选没有填充物而偏好中药填充。这些不是单纯提高已成功组权重就补出了新的决策知识。

原A后段窗口也存在F组中partial、循环等相对正优势，符合原GRPO定义。但本次实验表明，组是否见过成功不足以充当整组学习信号可靠性的判定器；它没有指出哪次搜索有效、哪次换规格丢了约束、何时应该回退或结束。

## 八、能解释到哪一步，以及后续主线

**已确认：** 局部需求匹配改善真实存在；早期相对领先会被原方法追平；已有成功路线有反复；大部分持续失败未被解决；组级重加权同时压/放正负优势，改变了已有信号分配而没有新增决策比较。

**最有依据的机制解释：** 用是否有成功这一粗标签统一调节整组，无法区分有用的失败比较、可能误导的正优势及需要保留的负反馈，因而可以改善部分动作选择，却没有形成覆盖检索、需求核验和终止恢复的一致收益。这与观察吻合，仍不是对最终参数变化的唯一因果证明。

**未确认：** 哪个训练组导致哪道Dev/Final退步、是否灾难性遗忘、不同seed能否复现、改成另一权重或只压F正优势是否有效、800是否收敛。历史对照有恢复/随机路径/成本差异；尾段skip50也已披露，不能声称全部条件相同。

下一轮主线应从“哪类比较值得学习、需求约束怎样落实到决策”重新提出可反驳的学习机制，而非继续把F=坏信号、S=好信号作为唯一依据。当前不直接推荐只压F正优势：partial质量未认证，偏置正负会改变原组内中心化性质，需要独立设计和验证。原来每组4轨迹、严格同历史局部比较覆盖不足的结论也不因本次分析自动失效，不重启旧分叉/局部优势方案。

优先保留两项要求：保护已有明确纠错作用的负反馈；区分产生新需求证据的探索和无进展循环。新方法必须先在训练题上证明它提供可靠的新区分，再冻结训练对照。少数评分歧义只登记备选，不改本次分数，不转向全面奖励修补。

python -X utf8 tools/analyze_group_weight_unified.py
