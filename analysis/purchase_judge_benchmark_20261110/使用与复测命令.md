# 历史购买自动核验：无卡测试与复测

本轮已在本地执行；下列命令用于复现、查看报告或在中断后续跑，不是新的GRPO训练。无需AutoDL或GPU。

## 已固定的数据和答案

- `dataset/`：88种训练购买组合及历史批次；旧v3/v4准备缓存，新v5验证覆盖。原始数据的哈希写在`dataset_manifest.json`。
- `dataset/reference_atoms.jsonl`：模型判断前完成的244项独立审阅参考，来自31种新购买组合。6项明确不符、72项未知、166项满足。此处“人工参考”是助手阅读原文的判断，不是新增用户签收，也不代表1000题总体准确率。
- `dataset/reference_rankings.jsonl`：4对同题商品奖励排序/等价检查。
- `api_probe/`：正式测试之前的2次API可用性探测，不参与独立准确率。
- `school_flash_v1/`：正式API调用日志、通过程序检查的回答、逐项准确率、奖励回放和按历史批次的等待实测。
- `decision.json`、`实测结论与训练方案.md`：最终汇总及训练方案选择。

## 本地配置

密钥保存在`D:\shopping_agent\.env.purchase-judge.local`，已由`.gitignore`忽略。文件格式如下，切勿提交真实密钥：

```dotenv
LLM_API_KEY=在本机填写
LLM_BASE_URL=http://aigw.dlut.edu.cn/v1
LLM_MODEL=DeepSeek-V4-Flash-0731-W8A8
```

也可以只在当前PowerShell设置同名环境变量，然后省略`--env-file`。默认HTTPS，只有显式`--allow-school-http`允许上述学校地址；不允许URL夹带用户名、密码、query或fragment。

## 仅在仍有失败项时续跑API

确认没有另一个同目录测试进程在运行。已通过的回答会复用，失败项会新增尝试；程序不会无限重试。续跑会发生真实API请求，所有尝试累计保留。

```powershell
Set-Location D:\shopping_agent
$env:PYTHONIOENCODING = 'utf-8'
.\.venv-llm\Scripts\python.exe .\tools\purchase_judge_benchmark.py run `
  --output .\analysis\purchase_judge_benchmark_20261110\school_flash_v1 `
  --env-file .\.env.purchase-judge.local `
  --allow-school-http --timeout 60 --concurrency 4
```

不要在API回答已经生成后重建或修改`reference_atoms.jsonl`。提示词、模型、并发或其他配置变化须使用新输出目录；程序会拒绝把不同配置的回答混在一起。对相同请求重复测出的第二轮低耗时主要反映缓存，不能当成冷启动速度。
