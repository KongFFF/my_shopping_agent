# 任务级成败与路径核查口径

2026-11-17，先固定口径后运行。仅用已有原在线351—500、651—800两窗全部生成组，区分实际更新与过滤组；状态分析限已认证的恢复轨迹。旧4192、B续段、Dev/Final均不用。不新增模型运行。

- 主统计单位为任务、同题四轨迹组及轨迹；任务成败统计只用四条均有效且组未标无效的生成组。原全量生成统计仍保留无效组分母。
- “未观察到成功”仅指两个导出窗口；不叫永久难题。“后段全成功”也仅指该任务在此窗口的有限样本，不叫能力稳定。单组四条不当四次独立训练阶段。
- 成功沿用原生reward_valid及purchase_success。按时间记录当前批次之前是否见过同题成功、见过几个不同成功组；不拿未来成功作为历史记忆证据。另可回顾两窗成功商品，定位失败路径相对已知成功商品的最深进展，明确这是含未来信息的离线诊断，不能作训练规则。
- 任务分为：后段无有效观测；后段全观测成功；后段有成功有失败；前段成功但后段全失败；两窗均未观察到成功。列出重复组数、成败数，不检验遗忘或给每题能力概率作精确估计。
- 对已认证公开搜索结果，严格按投影中可见ASIN计算新候选量、相同结果集合与重复查询；语义不同但结果相同不代表一定无效，相同ASIN也可能带来新规格信息。这些只诊断候选探索冗余。
- 对实际更新中的零成功组，检查最高奖励的部分匹配轨迹是否购买/打开/看到两窗其他轨迹实际成功的商品；同款不代表规格或语义正确。没有已知成功商品时记无法定位，不用隐藏目标填充答案。
- 这些材料不足以确认未成功题是否存在公开可解路径、确定梯度是否导致遗忘、验证成功回放或探索算法的收益。材料不足项直接报告，不能转成新训练推荐。
