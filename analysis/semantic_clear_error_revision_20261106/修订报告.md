# 第三步：明确错误的逐题修订（2026-11-06）

已基于r7固定的1000题修订稿，处理剩余14道阻断及已读审阅记录中的明确错误。本轮48题实际修改了数据，其中12题原来程序阻断、36题原来程序已通过。后者说明逐题语义修订与提高程序通过率是两件事。本轮不声称已逐题审完1000题，也不将整题标记为奖励可用。

没有新增阻断，没有重选回答，没有API调用、训练或评测模型。原任务集合仍是1000题；原LLM回答、r6/r7代码及历史报告保持不变。

48个数据修改不等于48个全部正确的最终标签：有些是撤去错误断言、恢复真实原文并保留待审。12道新增通过包含4888——其原来的1不必改写，本轮通过来自用户确认的来源解释；不能把它算作新改了一道回答。

- 3527/19395等：不凭外部知识补品牌、讲师类型、年份或预算边界。

## 新确认的数量政策

用户本轮明确确认：对象明确时，加个／配个／有个按1个处理。已应用于明确对象，并在独立的 `r7-review` 审阅校验中保存来源证明。该校验不创建数量、不推强弱，不把有个朋友中的一个借给商品，也不批准整题；冻结r7没有改动。

政策记录见[user_decisions.json](user_decisions.json)，6项新边界测试通过。原r7相关78项测试对应代码保持冻结，哈希在本轮全量核验中再次一致。

本政策命中的2147、4888、7831均已核对对象与计数来源，记录见[数量来源复核](quantity_proof_review.json)。7831的30*30仍是原文字面规格，没有据此补单位或认为是30件；数量证明不代表整题尺寸已获批准。
