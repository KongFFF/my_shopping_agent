# 完整50题初审后的r3修改说明

本轮完成了可以明确判断的程序修复、r3提示词整理和已有回答的离线回放。原训练1000题、固定50题ID及原始query、r2代码和源结果均保留；没有调用真实API，没有启动评测或训练。

## 已实现

1. **受控字段路由**：已有合法subtype归到唯一对应维度；power/voltage/drive_structure仅按封闭属性表归入function。未知类型、错误单位和虚构分母仍拒绝，不使用兜底类型吞掉问题。
2. **角色纠正并记录审计**：普通售价误归无分母单价时，依原文纠正为整单预算；明确包邮归运费0；书本数量、单支包装和重量包装分别处理；防水等功能不归成色；邮寄来源不归生产地；明确赠品不误作普通组件；达到的能力下限保留。
3. **证据与提示词**：用已有evidence数组分别引用主体及属性，不猜主体，也不模糊改写原文；重写r3提示词，明确计价、数量、对象及强弱规则。提示词正文从r2的9745字节整理为约7.7KB，仍由入口追加schema和合成示例。
4. **增加语义拦截**：类别混入规格、功能/交流转换关系遗漏、课程级别误作商品版本、配件与适配型号作用域不明、包装/附件误作购买数、材质颜色合项、颜色性能合项、自然与无添加合项、双驱动与气轮合项、质保基础要求与时长偏好合项等。
5. **独立版本及入口**：新增`--profile semantic-v2-r3`，保留旧profile；校验入口识别r3版本；保存并检查关系规则源码快照。诊断入口支持只有准备文件而没有历史日志的源目录，便于固定协议后一次收集全部50题。

## 离线回放结果

对同一批50份r2原始回答做显式版本适配，然后运行r3程序；没有生成新的模型回答，没有手动替换这些回答来凑通过率。

- r2原程序通过36题；同批旧回答在r3下通过23题。
- 旧失败中的12459（场景数组路由）和12852（五斤装净含量）恢复程序通过。
- 旧通过中的15题被新增语义检查拦截：3499、3876、4971、8784、10086、12134、12748、16177、16730、17111、17803、18609、21120、22210、22560。
- 某些旧失败已经修正第一层问题，但第二层错误仍保留。例如21051驱动字段的路由已修正，双驱动与气轮仍未拆开，因此继续拦截；13045功能路由修正后，漏提购买1个的问题被原数量检查发现。
