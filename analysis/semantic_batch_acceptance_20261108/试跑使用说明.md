## 本地提交与推送（无卡）

本轮由助手按白名单选择并提交代码、冻结数据、审阅账本及验收证据。权重、虚拟环境、`outputs/`里的API尝试/训练中间产物、缓存和重复的大型回放文件不纳入提交。逐文件清单见同目录`git_publication.json`。

上游子模块固定在原作者的公开提交；其8个本地训练入口改动以`experiments/evidence_training_runtime_v1/`源码快照随主仓库提交。AutoDL拉取后必须执行下方安装步骤，不能只更新子模块就认为已得到新训练入口。

后续本地有新改动需要同步时，在PowerShell中执行以下命令。助手本次已经完成的提交无需重复创建：

```powershell
Set-Location D:\shopping_agent
$env:PYTHONIOENCODING = "utf-8"
.\.venv-llm\Scripts\python.exe tools/prepare_git_publication.py --stage
if ($LASTEXITCODE -ne 0) { throw "文件选择或暂存检查失败" }

if ($LASTEXITCODE -ne 0) { throw "push未成功，请检查Git输出" }
```

如果修改了这8个上游源码文件，需同时更新对应快照、哈希及奖励放行冻结清单后再提交，不能让快照与实际测试代码不一致。

## AutoDL预检（无卡即可）

先在AutoDL终端拉取主仓库及固定的子模块版本。以下步骤均可无卡执行；`--ff-only`不会自动合并或覆盖同名本地改动。上游源码安装器会把被替换文件逐字节备份到`outputs/evidence_runtime_backups/`，不修改数据集、环境manifest或权重。

```bash
cd /root/autodl-tmp/work/my_shopping_agent
set -euo pipefail
git status --short
git pull --ff-only origin main
git submodule sync --recursive
git -c 'url.https://github.com/.insteadOf=git@github.com:' submodule update --init --recursive

export PROJECT="$PWD/upstream/shopping-grpo-longhorizon"
export PY="$PROJECT/.venv/bin/python"
test -x "$PY"
"$PY" tools/install_evidence_training_runtime.py --apply --backup-existing
"$PY" tools/install_evidence_training_runtime.py --check
git log -1 --oneline
```

安装器显示8个文件均为`installed`后，再继续预检。安装后的子模块显示本地修改属于预期，这些改动的源码已随主仓库快照上传，无需向原作者仓库push。manifest会拒绝缺失文件或版本不一致。

下面采用此前记录的仓库及SFT路径，任何路径不存在都应先停止核对：

```bash
cd /root/autodl-tmp/work/my_shopping_agent
set -euo pipefail
export PROJECT="$PWD/upstream/shopping-grpo-longhorizon"
export PY="$PROJECT/.venv/bin/python"
```

通过后做命令构建预检；`--dry-run`不加载模型、不连接环境、不开始训练，不需要GPU：

```bash
"$PY" "$PROJECT/scripts/train_grpo.py" \
  --model "$SFT_MODEL" \
  --output "$PILOT_OUT" \
  --env-url http://127.0.0.1:5700 \
  --logger console \
  --experiment-name semantic-evidence-pilot20-v1 \
  --evidence-reward-manifest "$EVIDENCE_MANIFEST" \
  --reward-tools-dir "$REWARD_TOOLS" \
  --dry-run -- \
  trainer.total_training_steps=20 \
  trainer.resume_mode=disable \
  data.train_batch_size=2 \
  actor_rollout_ref.rollout.n=4 \
  shopping_dynamic_sampling.enable=true \
  shopping_dynamic_sampling.max_num_gen_batches=3 \
  shopping_dynamic_sampling.max_consecutive_skipped_updates=3 \
  trainer.val_before_train=false \
  trainer.test_freq=-1 \
  trainer.save_freq=20
```

输出目录必须是新目录或空目录；不要混入旧GRPO训练结果。若报依赖/冻结文件不一致，先修复同步或环境，不要直接改manifest。
