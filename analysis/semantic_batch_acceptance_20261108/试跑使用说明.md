## AutoDL预检（无卡即可）

先在AutoDL终端拉取主仓库及固定的子模块版本。以下步骤均可无卡执行；`--ff-only`不会自动合并或覆盖同名本地改动。上游源码安装器会把被替换文件逐字节备份到`outputs/evidence_runtime_backups/`，只允许修正环境清单中此前已确认的源码哈希，不修改数据集、奖励规则或权重。

```bash
# 清除之前粘贴命令留在当前交互终端的退出选项。
set +e
set +u
set +o pipefail
shopping_sync_code() {
  cd /root/autodl-tmp/work/my_shopping_agent || return
  git status --short || return
  git pull --ff-only origin main || return
  git submodule sync --recursive || return
  git -c 'url.https://github.com/.insteadOf=git@github.com:' submodule update --init --recursive || return
  export PROJECT="$PWD/upstream/shopping-grpo-longhorizon"
  export PY="$PROJECT/.venv/bin/python"
  test -x "$PY" || { printf 'Python不存在或不可执行：%s\n' "$PY"; return 1; }
  "$PY" tools/install_evidence_training_runtime.py --apply --backup-existing || return
  "$PY" tools/install_evidence_training_runtime.py --check || return
  git log -1 --oneline
}
if shopping_sync_code; then
  printf '代码同步与安装成功，继续下面的无卡预检。\n'
else
  rc=$?
  printf '代码同步或安装失败，退出码=%s；终端保留，请先检查上方错误。\n' "$rc"
fi
unset -f shopping_sync_code
```

### 启动并实测ShopSimulator服务（CPU操作，在将训练的同一实例执行）

最新报错`[Errno 111] Connection refused`发生在`reset`连接`127.0.0.1:5700`时。奖励后端/Ray路径检查不等于HTTP环境已启动。下面复用原正式复现的环境启动方式；它只运行CPU服务，不启动模型服务。

请在实际即将训练的实例上执行。切换无卡/有卡模式或关机会结束后台服务；切换后需要重新执行本节，而不是仅依赖之前的预检结果。日志放在独立services目录，避免提前把训练输出目录变成非空。

```bash
set +e
set +u
set +o pipefail
cd /root/autodl-tmp/work/my_shopping_agent
export PROJECT="$PWD/upstream/shopping-grpo-longhorizon"
export PY="$PROJECT/.venv/bin/python"
export SERVICE_DIR="$PROJECT/outputs/runs/semantic_evidence_pilot20_services"
mkdir -p "$SERVICE_DIR"
export SERVICE_LOG="$SERVICE_DIR/environment_$(date +%Y%m%d_%H%M%S).log"

if "$PY" - <<'PY_CHECK'
import socket
try:
    with socket.create_connection(('127.0.0.1', 5700), timeout=2): pass
except OSError:
    raise SystemExit(1)
PY_CHECK
then
  printf '5700已监听，不重复启动；继续检查真实API。\n'
else
  nohup env PYTHONUNBUFFERED=1 PYTHONPATH= OMP_NUM_THREADS=1 \
    SHOPSIM_PORT=5700 SHOPSIM_ENV_SLOTS=8 SHOP_MAX_STEPS=35 \
    bash "$PROJECT/scripts/start_environment.sh" \
    > "$SERVICE_LOG" 2>&1 < /dev/null &
  printf '%s\n' "$!" > "$SERVICE_DIR/environment.pid"
  printf '环境启动日志：%s\n' "$SERVICE_LOG"
fi

if "$PY" tools/probe_shopsim_service.py \
  --base-url http://127.0.0.1:5700 --wait-seconds 120 --slots 8
then
  printf '环境API、8个独占槽位及释放均通过，继续Ray自检。\n'
else
  printf '环境尚未就绪，不启动训练；检查下面的服务日志。\n'
  if test -f "$SERVICE_LOG"; then tail -n 80 "$SERVICE_LOG"; fi
fi
```

应看到`environment_service_probe_passed: true`、`slots_verified: 8`、`leases_released: true`。探针只reset并释放本次申请的租约，不购买商品，不调用`release_all`，不会清空其他会话。
