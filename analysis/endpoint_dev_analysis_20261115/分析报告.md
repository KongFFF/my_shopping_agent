# 750／800新端点失败分析

2026-11-15。已完成真实回传核验、四模型逐题对照及全部新端点失败的助手审阅。没有训练、重新运行模型、调用付费API或读取Final具体任务。

## 核心结论

800仍有明确的可见规格／预算／购买状态决策错误；500时期的这一短板没有因延长训练而消失。但剩余失败同时包含信息不足、隐藏要求和流程填槽信号，不能把所有partial都解释为模型不会选规格。

原配方续训已经改善了部分候选恢复与执行稳定性。750→800的Dev净增2题却不是2个纯粹语义修复；新增和退化各自涉及不同机制。现有证据支持把“可见需求与当前SKU／价格／购买状态的核对”作为下一阶段研究子问题，不支持立即指定一个算法长训，也没有把同策略有效组保留升级为能力改进主线。

## 实际新增成功意味着什么

1. **13399硬盘底座**：500停在48TB候选；750/800继续找到了公开标注80TB、脱机克隆＋联机读写的699元迷你标准版。支持候选恢复与需求匹配改善，更多步骤在这里有实际价值。
2. **14141洁牙设备**：750循环，800找到阿里健康大药房、军绿色357元且标题/属性更贴近可视家用需求的候选。支持可见候选利用改善，不验证实体医疗性能。
3. **8666压脚**：相对500，800的1个→买10送1有真实数量改进；但750早已选对买10送1，750→800的新增gold主要来自补点单值“规格”轴。
4. **2898**是缺少公开映射的代码切换，**3485**则是公开标准款选择的回退。因此750→800净增2题，不应直接讲成2题明确语义修复。

## 规格反事实上界：有空间，但不要把上界当收益

对800购买原目标却失败的10题，在固定目录及原Reward v3下枚举可选规格，10题均完整枚举（最多84组合）。9题存在gold组合，14929没有。

9题中包括上述5道可见决策案例，也包括`0lb`、预定告示轴、隐藏打孔和31A等问题。9/50=18个百分点只是使用隐藏标注的原评分反事实上界，不能作为预期Dev增益，更不能外推Final。不能把正确组合喂给Actor或用来挑分叉状态。

## 对改进方向的更新

**可以完成阶段判断：后段仍有未解决的公开需求—规格／价格—购买状态核对问题，且候选恢复也重要。** 这比“partial最多，所以要做局部信用分配”更具体，但尚未证明任何采样或损失改动有效。

- 同策略有效组保留继续作为效率支线；本次Dev失败分析不能证明回收组能修复这些错误，也没有统计651—800丢弃组的具体语义内容。
- 若研究能力改进，建议把下一项候选限定在“公开页面下，关键规格或购买前决策是否能产生可信的成败比较”。先在训练1000题上检验可探索性与信号；不能用这些Dev题构造训练集或硬编码触发条件。
- 原首次详情分叉失败的证据仍有效，不因新端点有局部错误就自动重启。更晚触发／更局部比较可能值得小探测，但必须同时证明覆盖率、比较质量和成本，包含未触发及仍需换候选的任务。
- 不建议重开全量语义评分器，或对所有步骤统一惩罚。800相对750循环显著减少，13399的有效恢复又确实需要更多步骤；两类行为应分别分析。
- 本轮结束于诊断，不启动新的采样、训练或Final。下一步方法选择仍需结合预算与训练题证据；报告不能将局部缺陷直接当算法瓶颈的因果证明。
