# 新采样顺序：无卡预检与20步试跑命令

本轮限定最多20次优化器更新，仍从原SFT step300出发，保留原1000题及19题整组无效政策。不是500步正式训练，也不是重复旧v3目录。先执行无卡步骤，再切换有卡；切换实例/模式后重新设置变量并检查环境服务。

上次3步采到的12题全部在此前审阅范围内。本次只改变数据采样器种子为20261110，模型仍从同一SFT step300出发，原1000题、parquet、奖励包和其他采样参数保留。前24题允许自然重叠，不人为挑题。`PYTHONHASHSEED=42`继续保留，它不是数据采样器种子。

veRL参考：[数据配置](https://github.com/volcengine/verl/blob/v0.8.0/verl/trainer/config/data/legacy_data.yaml)、[create_rl_sampler](https://github.com/volcengine/verl/blob/v0.8.0/verl/trainer/main_ppo.py)。真正生效与否仍以第4步对本机已安装采样器的检查为准。

## 4. 实测采样顺序（无卡）

该命令只读取parquet并调用CPU采样器，不加载模型、不启动训练，也不修改训练文件。先看到`preview_passed:true`，再继续。若导入、配置或断言失败，保留输出，不先开卡。

```bash
"$PY" - <<'PY_PREVIEW'
import importlib.metadata
import ast
import hashlib
import json
import os
from pathlib import Path
import pyarrow.parquet as pq
from omegaconf import OmegaConf
import torch

# Execute only the actual installed sampler function, not the model launcher.
source=Path(importlib.metadata.distribution("verl").locate_file("verl/trainer/main_ppo.py"))
tree=ast.parse(source.read_text(encoding="utf-8"))
fn=next(n for n in tree.body if isinstance(n,ast.FunctionDef) and n.name=="create_rl_sampler")
fn.returns=None
for arg in list(fn.args.args)+list(fn.args.kwonlyargs):
    arg.annotation=None
module=ast.fix_missing_locations(ast.Module(body=[fn],type_ignores=[]))
namespace={"torch":torch}
exec(compile(module,str(source),"exec"),namespace)
create_rl_sampler=namespace["create_rl_sampler"]

root=Path.cwd()
assert importlib.metadata.version('verl')=='0.8.0'
project=Path(os.environ['PROJECT'])
ids=[int(x['task_id']) for x in pq.read_table(project/'data/grpo/train.parquet',columns=['extra_info'])['extra_info'].to_pylist()]
assert len(ids)==len(set(ids))==1000
config=OmegaConf.create({'shuffle':True,'seed':20261110,'sampler':{'class_path':None,'class_name':None}})
a=list(create_rl_sampler(config,ids))
b=list(create_rl_sampler(config,ids))
assert a==b and len(a)==len(set(a))==1000
ordered=[ids[i] for i in a]
old=[]
for line in (root/'analysis/semantic_evidence_pilot3_v4_results/training_diagnostics.jsonl').read_text(encoding='utf-8').splitlines():
    e=json.loads(line)
    if e['event']=='generation_batch':
        for g in e['groups']:
            old.append(next(r['task_id'] for r in e['rollouts'] if r['uid']==g['uid']))
assert ordered[:len(old)]!=old, '采样前缀仍与旧试跑相同，先检查seed配置'
reviewed={r['task_id'] for r in map(json.loads,(root/'analysis/semantic_pilot30_evidence_20261109/review_inputs35.jsonl').read_text(encoding='utf-8').splitlines())}
result={'preview_passed':True,'data_seed':20261110,'sampler_source':str(source),'sampler_file_sha256':hashlib.sha256(source.read_bytes()).hexdigest(),'first24_task_ids':ordered[:24],'first24_outside_reviewed_tasks':[t for t in ordered[:24] if t not in reviewed],'same_order_on_repeat':True,'training_parquet_modified':False}
service=project/'outputs/runs/semantic_evidence_pilot20_v5_services'
service.mkdir(parents=True,exist_ok=True)
(service/'sampling_preview.json').write_text(json.dumps(result,ensure_ascii=False,indent=2)+'\n',encoding='utf-8')
print(json.dumps(result,ensure_ascii=False,indent=2))
PY_PREVIEW
```

这只是parquet行顺序的无卡预览。训练过程中若数据加载器过滤超长输入，实际任务前缀可能略有不同；最终以`training_diagnostics.jsonl`为准。

## 5. 检查ShopSimulator和Ray（CPU操作，在实际有卡训练实例上执行）

切换有卡模式后，先重新执行第2步设置变量，再执行本步骤。此步骤不加载模型、不做训练，但环境服务必须与随后训练位于同一实例。

```bash
cd /root/autodl-tmp/work/my_shopping_agent
export SERVICE_DIR="$PROJECT/outputs/runs/semantic_evidence_pilot20_v5_services"
mkdir -p "$SERVICE_DIR"
export SERVICE_LOG="$SERVICE_DIR/environment_$(date +%Y%m%d_%H%M%S).log"
if "$PY" - <<'PY_CHECK'
import socket
try:
    with socket.create_connection(('127.0.0.1',5700),timeout=2): pass
except OSError:
    raise SystemExit(1)
PY_CHECK
then
  printf '5700已监听，继续API检查。\n'
else
  nohup env PYTHONUNBUFFERED=1 PYTHONPATH= OMP_NUM_THREADS=1 \
    SHOPSIM_PORT=5700 SHOPSIM_ENV_SLOTS=8 SHOP_MAX_STEPS=35 \
    bash "$PROJECT/scripts/start_environment.sh" \
    > "$SERVICE_LOG" 2>&1 < /dev/null &
  printf '%s\n' "$!" > "$SERVICE_DIR/environment.pid"
fi

if "$PY" tools/probe_shopsim_service.py \
  --base-url http://127.0.0.1:5700 --wait-seconds 120 --slots 8
then
  "$PY" tools/probe_evidence_ray_worker.py \
    --manifest "$EVIDENCE_MANIFEST" --reward-tools-dir "$REWARD_TOOLS" \
    --env-url http://127.0.0.1:5700
else
  printf '环境API未通过，暂不启动训练。\n'
  if test -f "$SERVICE_LOG"; then tail -n 80 "$SERVICE_LOG"; fi
fi
```

须先看到服务探针通过，以及Ray输出`nested_ray_probe_passed:true`、`released_tasks:981`、`held_tasks:19`，再执行下一步。
