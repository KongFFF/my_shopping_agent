# 局部信号CPU资格核查协议 v1

2026-11-17，执行前固定。仅使用上轮清单中的原在线两窗、已认证公开状态恢复及固定800自然A整局；不用B续段、4192、Dev/Final或新采样。不调奖励、不训练。

1. 按原同题四轨迹组分析，不跨策略版本拼组；原训练限四条均获认证的更新组。冻结800单列均匀32与富集16。轨迹是支持量单位，每个状态每条轨迹仅首次访问；排除初始状态。
2. 三种预动作键：公开页面文本；页面+剩余步数；页面+此前工具动作和公开观察历史。第三种不含assistant思考，不能称完整策略上下文。动作严格按工具名和参数规范化，不合并近义搜索。
3. 对比原整局优势E=R-四条均值，朴素局部优势L=R-到达状态轨迹均值，以及动作平均局部优势M=该动作平均R-到达状态均值。γ=1，不引入长度折扣。报告L与E是否相同、仅同比缩放或方向/大小分配改变；M独立报告，不能据L的覆盖推断M。
4. 可靠性只对至少两种动作、每种动作至少两条独立轨迹的状态作证据拆分。四轨迹约束下为2+2：枚举两种不重复的互补拆分，每半各一种动作，记录同向非零、反向、含平局。候选选择不看回报。原生连续奖励和原生成功0/1分别检查。全部平局不算正确排序；不可拆分记证据不足。不同状态/拆分相关，不做独立样本显著性宣称。
5. 上轮明确语义/环境惯例不确定的22462、19827只作排除敏感性分析；不修改其原生分数，不将所有其他题当作已语义验真。
6. CPU继续资格采用保守预算筛选标准（工程决策门槛，非统计定律）：后段严格历史键下，独立可拆分且两种奖励口径均无反向、每个拆分均同向非零的信号至少覆盖20个更新组、15道题；其中局部优势确有区别于原E的至少10组、10题。即使通过也只允许考虑短训练协议，不证明性能有效。未通过则不推进该具体构造至GPU，不放宽规则追通过。

同时报告门槛前后每一级分母、排除敏感性，以及若采用动作均值构造M能否满足同样要求。历史窗口稳定性只是不同阶段描述，不混作同策略独立验证。
