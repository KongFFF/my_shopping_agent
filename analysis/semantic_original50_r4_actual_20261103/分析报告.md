# 原50题r4新调用对照审阅（2026-11-03）

## 结论

当前端到端流程有明显改善，尚不满足扩大1000题的门槛。当前输出仍有程序漏检的语义错位和少量明确退化。本轮只分析，不继续新增单题规则，没有调用API、改动提取代码或读取封存新50题的题文。

## 同一校验器对照

两轮原始回答都使用当前r4校验器只读重验。旧回答的版本字符串显式适配，原始内容不变。旧提示词与新提示词不同，因此这比较的是端到端提取流程，不能单独归因于LLM基础能力。

| --- | ---: | ---: |
| 首次回答通过 | 24/50 | 27/50 |
| 重试后通过 | 25/50 | 42/50 |
| 实际调用数 | 96 | 73 |

新一轮27题首次通过，15题在第二次后通过，8题两次均失败，所有73次HTTP 200。最终通过率84%，首次通过率54%。旧一轮首次24题通过、重试后25题，因此本轮最终改善主要体现为错误反馈/重试开始有效。旧96次还包含脚本类型异常引起的无效重试，调用减少不等于单个模型能力显著变强。

新获程序通过：2547, 3499, 4971, 6401, 11639, 12697, 12748, 13045, 13946, 16609, 16730, 18609, 19764, 20025, 20357, 21051, 21120, 22210。
旧通过而本轮失败：12769。

## 逐题语义初审

- 24题仍需修订：8题程序失败，16题虽然通过程序仍有语义或字段口径问题。
- 19题主要为真实含义或证据标准待审。它们不等于模型理解错误，也不因为形式通过就可评分。
- 7题暂未发现明确需求改写错误，商品事实仍未核验。
- 全部合同仍未人工批准。这是本助手的保守初审分类，不是独立真值准确率，也没有机械按参考稿文本一致性算分。

## 主要改善

预算和运费恢复稳定；2547赠品不再默认各1；3499类别不再包含一寸；4971超轻从类别分开；11639明确用途回归需求；13045/13946/20357补回购买数；19764课本级别回到content；22210框颜色材质拆开。背景误待审也明显减少。

## 残留的通用问题

1. 字段合法但含义错位：3723造型仍归pattern，12748初乳仍作附件，13045一机多用放form_factor，21051双驱动气轮改放form_factor，绕过了原先只检查drive_structure的盲区。不推断模型有意规避，只说明结构通过不足以证明语义正确。
2. 来源与逻辑保真：14894尺码190被无依据补成190mm；17803在原文明示不清的情况下又写one_of，尽管仍有pending；21998漏圆领。
3. 未通过8题以主体引文、关系/类型、唯一引文和计价分母为主，涉及5598、6547、8784、9294、12459、12769、14222、22560。
4. 主观、近似和真实特殊语义继续待审，不编品类阈值、不追求当前试点清零。

## 参考稿也要保留可修订性

12126原文只说细钢直条规格不超过0.5毫米，没有明说几何量。新答的厚度、参考稿的直径都不应当作无歧义真值。本轮将这一点标记为需复核，不把与参考稿不一致机械算错，也不为它新增运行时特判。

## 下一步建议

暂不扩大1000题，不再整批重复旧50。建议保持当前版本，在封存新50题上做一次独立诊断，确认剩余模式是否在普通随机样本中普遍存在。这不是宣称已达到验收门槛。随后只集中处理原文单位/逻辑保真、字段角色和通用结构等问题，必要时在同条件小样本比较抽取模型，停止按特殊词逐题扩规则。

新50题应分别报告首次/重试通过、语义需要修改、真实未决、可用于奖励的覆盖。单题复杂表述是否值得人工投入，由随机验证后的总体收益决定。
